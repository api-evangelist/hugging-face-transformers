Agentic Resource Discovery (ARD) is a discovery layer that sits in front of protocols like MCP, Skills, and A2A, enabling agents to locate capabilities at runtime rather than requiring pre-installation. The Hugging Face implementation, called the Discover Tool, lets agents search for MCP servers, skills, and other resources through a standardized REST API and specification developed collaboratively across the industry.
